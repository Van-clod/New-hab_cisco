Команди й скорочення

Введи ?, щоб побачити команди поточного режиму, або show ?, щоб побачити продовження. Кожне слово можна скоротити до однозначного префікса.


Вхід у налаштування: en, conf t, int g0/0.


Діагностика: sh ip int br, sh int g0/0, sh int desc, sh run, sh ip ro. У режимі налаштування спробуй do sh ip int br.


Порт: desc До комутатора, shut, no shut, no desc. На маршрутизаторі можна видалити адресу через no ip add або статичний маршрут через no ip ro МЕРЕЖА МАСКА ШЛЮЗ.


Для швидкої перевірки вибери PC1 і виконай ping 192.168.1.20.
